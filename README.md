# nielspac177.github.io

Personal academic webpage for Niels Pacheco-Barrios, MD, MSc.

Plain static HTML + CSS, served by GitHub Pages at https://nielspac177.github.io.

## Files

- `index.html` — landing page (bio, links, selected publications)
- `publications.html` — full publication list
- `teaching.html` — teaching appointments and course materials
- `style.css` — single stylesheet
- `photo.jpg` — profile photo
- `cv.pdf` — current CV

## Updating

Edit the HTML directly, commit, and push. GitHub Pages rebuilds automatically within a minute.

To update the CV, replace `cv.pdf` with the new file (keep the filename).
